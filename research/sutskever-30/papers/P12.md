Try each question from memory before revealing the explanation.

### 1. What do message passing and readout do in an MPNN?

<details>
<summary>Reveal explanation</summary>

Message passing aggregates edge-neighbor information and updates node states; readout combines node states into a graph-level output.

</details>

### 2. Why is summing neighbor messages useful for a molecular graph?

<details>
<summary>Reveal explanation</summary>

The aggregation is insensitive to neighbor order, which should not change the represented molecule.

</details>
