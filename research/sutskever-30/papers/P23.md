### 1. What are the two main terms in the MDL tradeoff?

<details>
<summary>Reveal explanation</summary>

The model description length plus the data description length given that model.

</details>

### 2. Why might an interpolating polynomial lose under MDL?

<details>
<summary>Reveal explanation</summary>

Its larger model code may cost more bits than it saves in residual code length.

</details>
